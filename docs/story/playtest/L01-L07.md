# 《碑誓》L01–L07 文字試讀

本輪目標是閱讀與選擇，不是完整戰棋遊戲。故事／規則未正式採用；沒有真人人類回饋紀錄，狀態為 **待人工審查**。

## 開啟方式

本輪工作區已建出 `scratch/story-playtest/index.html`，可直接用瀏覽器開啟，同資料夾檔案需保留。可離線閱讀，不需登入、不上傳資料。從 repo 重建的版本與命令見 [story-playtest/README](../../../story-playtest/README.md)。沒有部署公共網站。

一般從頭閱讀，不先打開「路線比較」以免劇透。操作：選項按鈕、回上個選項、重新開始、放大文字。結尾可以匯出 JSON 選項紀錄，其中含劇本 sourceHash、每步選項與重播 URL；重播只適用相同 sourceHash，更新稿本後請從頭讀。回退保留修改前選項，重新開始會清空本次路線；沒有正式存檔。

「路線比較（含劇透）」提供 K1 開／封 × L07 救昆／救盤／護薩溫 × 收留／拒收的十種有效組合。拒收薩溫沒有護薩溫選項。高低公開勇氣差異可透過 L05 是否請托瑪治療、L07 是否質問收容禮重讀；信任數字不顯示。戰果選項明確是文字模擬，不記為人類實戰。

## 建議真人試讀路線

1. 第一次完全自由選，不看矩陣。讀到 L03 前先用自己的話寫下各選項所得、所失與不知道的事，再選。
2. 走一次開閘＋救小昆；另走封閘＋救星盤，並比較對伊瑟拉、蕾絲與名鑰的理解。
3. 在收留薩溫路線比較三種 L07 保護；拒收路線確認沒有憑空復現。把托瑪的低／高公開勇氣各讀一次。
4. 比較多／少撤離與是否拖延；不要把 #sim 當作自己的戰棋表現。

## 回饋題目（先自由回答，再看提示）

- 凱倫現在想取得什麼？你在哪一句看見他的缺陷？
- 名鑰是什麼？你是聽到誰的說法，還是親眼確認？K1 封閘是否已經救了北岸四百人？
- 為何提歐救回後又出航？你覺得是他自己的選擇，還是編劇強迫？
- 你最在乎燈芯屋／小昆／伊瑟拉／薩溫中的誰，哪一件互動造成這感受？也可以回答沒有。
- K1 哪個選項像標準答案？理由是資訊不足、價值偏好，還是未來補救讓代價失效？
- L07 你認為能救什麼、不能改變什麼？為何隊友不能同時救另外兩處？你是否仍覺得被強迫？
- 低信任托瑪是否讓你以為他贊成收魂？公開作證差異是否合理？
- 章末筆記、小昆、星盤、提歐與薩溫各在哪裡？有哪個角色知道了你沒聽到來源的資訊？
- 你是否想繼續第三章？要追的是哪個具體人物／問題？
