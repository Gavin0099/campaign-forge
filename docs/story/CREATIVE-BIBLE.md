# Campaign Forge：共同產品基準

版本：2026-10-21 候選基準。此文件是故事、戰術與美術的共同規格入口，不取代 DECISIONS 的決策權限。與上層衝突時依 [正典順序](CODEX-HANDOFF.md) 回報，不由本文件自動定案。

## 權限與核心體驗

| 狀態 | 內容 |
| --- | --- |
| 已確認的產品方向 | Steam／PC 原創奇幻戰棋 RPG；小隊職能與冒險、戰役推進、具代價的選擇；來源見 [DECISIONS](../DECISIONS.md) |
| 已確認的展示方向 | Owner 選「戰地測繪」深入打磨；不等於商業美術驗收通過 |
| 優先候選 | 《碑誓》L01–L07；救援、取證、撤退承接同一套人物價值衝突；G004 未通過 |
| 本輪可審查規格 | 本文件、[L03 候選切片](L03-VERTICAL-SLICE.md)、局部修正試讀；沒有新戰棋引擎或 main 角色替換 |
| 待決 | G004 故事採納、G005 SRD 子集或原創規則、正式名稱、最終人物與美術、後續開發預算 |

玩家扮演曾替別人決定犧牲的護衛，在戰場上安排誰守住退路、誰去救人、誰保住證據；戰後必須繼續與付出代價的人同行。差異化不是黑暗或死亡數量，而是「名字既是紀念，也是制度奪取人的方式」與「同伴合作不等於原諒」之間的衝突。

核心循環：具名人物與需求 → 有來源的資訊 → 戰役選擇 → 具體戰場目標 → 撤離與損失 → 人物反應與下一次任務。戰鬥不能只清敵後用過場收走剛救下的人；若劇情必有損失，操作前要讓玩家知道可爭取與不可改變的邊界。

## 敘事身份與原創職能

《碑誓》是關於責任、同意與被制度抹平的名字；黑暗奇幻需要燈芯屋、爛笑話與紙星星提供可失去的溫度。反派以保護為由剝奪同意，主角容易重演相同行為。資料證據不是自動正義，救眼前的人也不免除後續代價。

以下是 STORY 已有的敘事職能候選，不是職業數值或新能力。

| 人物 | 隊伍需求／原創世界解釋 | 在戰場上應讀到什麼 | 缺席時的代價 |
| --- | --- | --- | --- |
| 凱倫／Fighter | 前守碑騎士，守線與護衛；願望是重審封門罪 | 腳步接地、固定武器、身體擋住窄道，命中與受擊有同一接觸點 | 主角的責任不能用替身消除；倒下屬任務失敗候選 |
| 蕾絲／Rogue | 渡口走私客，運路、鎖與陷阱 | 偵察與精準趁隙，有可讀的資格與目標資訊；不是隱形無代價處理所有機關 | 強攻／長路成本，失去她的證人與私人判斷 |
| 托瑪／Cleric | 黎明誓院醫療修士；保護病傷者，拒絕為收魂祝聖 | 治療要讀得到目標與身體接觸／距離區分；守護對象與被囚魂不可混同 | 消耗品／撤退壓力，沒有憑空代班牧師 |
| 伊瑟拉／Wizard | 灰燈學院碑文學者，研究與控制 | 施法有準備、目標與效果階段；符文先是能讀的知識，不是每種能力都同色光球 | 碑文取道更長、知識與名鑰解讀受限 |
| 薩溫／Sorcerer 提案 | 被植入裂潮碎片的逃兵，體內魔力不是天生血統 | 身體承受力量的負擔與持續傷勢；不能把紅色爆炸直接當職業規則 | 爆發職能與邪教證詞缺失；不拿他做必需鑰匙卡主線 |
| 歐朵／Ranger | 邊境獵人，下游救人與地形經驗 | 清楚的觀察、射線與落腳點；有招募條件 | 同行者較慢找路，不憑空繼承她的知識 |

## G005 與 SRD 5.2.1 的邊界

依 [dnd-framework](../../.codex/skills/dnd-framework/SKILL.md) 先定職能再查來源；[官方 SRD 頁](https://www.dndbeyond.com/srd) 與 [5.2.1 PDF](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf) 為候選來源，選用授權 CC BY 4.0。查閱日 2026-10-21；不混用 SRD5.1 數字、不採用非 SRD 世界／人物／插圖，也不把參考遊戲稱為授權素材。

本輪只參照既有 VD3 研究的能力分類，沒有採用新規則內容或賦予故事角色實裝法術。若 G005 選 SRD 子集，後續每項能力必須完成 [規則改編契約](../design/RULE-ADAPTATION-CONTRACT.md) 的 source_id、class_id、動作、資源、目標、判定、adaptation_reason、visual_contract、verification 全部欄位；格子改編從 SRD 的 Playing on a Grid 出發。任何欄位 TBD 都不得實作。若選原創規則，須重新寫原創契約與驗證，不能保留 5E 相容宣稱。

## 技能與戰術演出契約（跨能力共用，非新規則）

1. 預覽必須先說「誰可以用、目標是誰、會花什麼、目前為何可／不可用」。距離、LOS、掩體、資源與資格在 G005 前只列待決，畫面不可假裝已判定。
2. 演出由準備 → 可辨識的動作／飛行 → 接觸或到達 → 一次結果提交 → 恢復／消散構成。視覺時鐘與資料提交共用事件；取消、重複確認與卸載不可重複結算。
3. 物理近戰先有姿態與刀刃接觸；奧術飛彈有獨立軌跡與目標分配；治療與持續守護需要不同語言。不可只靠更換發光顏色區分職能。
4. 持續效果要有持續狀態、期限／集中提示與結束原因，瞬間護印不能冒充有集中規則的持續法術。
5. 降低動態效果仍保留目標、結果與一次狀態提交。特效不可蓋過單位、血量、目的地或選項；任何傷害數字都應來自被核准規則，VD3 固定3不是正式傷害。

驗收分離：事件／資源／目標／取消可用工程測試；職業辨識、受擊重量與人物一致性需人工；戰術勝敗與目標公平要有真正遊戲操作，文字模擬不能替代。

## 戰地測繪與世界的連結

低飽和的紙、炭墨與河泥承載環境，人物保留有限識別色。界碑以承壓方向與裂縫組成地標；裂潮用侵入的等壓線及水位刻痕，危險範圍還要有形狀／文字；名鑰用索引與名字的細密刻痕；亡魂保留被抹掉又浮現的個人名字，不能畫成無差別可收集燃料。

這些是原創視覺提案，不是新增魔法機制。測繪線應服務高低、渡口動線、壓力與撤離，不用密集裝飾讓 UI 更難讀。11×9 地形與選取格同一投影；背景筆觸不能畫出不存在的可走橋面。

## VD3 的沿用與淘汰判斷

| 項目 | 本輪產品判斷 | 下一輪條件 |
| --- | --- | --- |
| 同源格線／地形投影 | 可重用工程方法，不沿用舊劇情地圖語意 | 以 L03 地圖實際標註絞盤、橋與船道後重驗 |

| 席恩立繪與小人、莉妲／奧倫／瑪芮圖集 | 保存為歷史／工程測試資產 | 不能直接改名算《碑誓》人物完成；先審人物剪影與職能 |
