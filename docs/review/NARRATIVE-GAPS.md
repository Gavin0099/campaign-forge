# S3.5 敘事缺口診斷

更新日期 2026-10-20。本文件是 S3.5「敘事強化」的輸入診斷，屬代理審查，不是玩家測試或 Gavin 驗收。

## 觸發

Gavin 表示「故事性還是不夠」，並於 2026-10-20 授權在 G001 選案前執行 S3.5：只保留單一故事、以 D&D 式框架（經典職業隊伍、地城與遺跡、魔法謎團、勢力）重建、加入施法者、可接受黑暗基調（同伴死亡與背叛）、加入一條感情線，且不必保留既有人名與道具。

## 借鏡 D&D 名作的可轉移原則

只取敘事原則，不使用任何作品的人物、地名、設定或情節。

| ID | 原則 | 參考 | 本專案落點 |
| --- | --- | --- | --- |
| P1 | 反派是被扭曲的美德，反覆現身並讓主角輸過 | Curse of Strahd | 大司碑以「保護」為名，第二章贏下一場對峙 |
| P2 | 每名同伴一條 2–3 拍的個人任務，與主線交織、可略過 | Baldur's Gate 3 | COMPANION-ARCS 個人任務 |
| P3 | 信任以隱藏的階段門檻運作，而非公開分數 | Baldur's Gate 3 | 四段信任：疏離／同行／信賴／誓約 |
| P4 | 沒有完美結局，人人須與選擇和解 | Baldur's Gate 3 | ENDINGS-MATRIX 不設全員圓滿 |
| P5 | 先讓玩家愛上具名的人與地，再讓威脅觸及他們 | Curse of Strahd 主持經驗 | 每章心之錨 |
| P6 | 冒險鉤子從角色背景長出 | Critical Role 等長篇戰役 | 每名同伴背景牽動一個主線事件 |
| P7 | 隊伍內部的分裂與背叛最痛 | Dragonlance | 第四章背叛節點 |
| P8 | 小而親密的開場、可見的倒數 | Lost Mine of Phandelver、Tomb of Annihilation | 第一章渡口小鎮；裂潮刻度每章上升 |

研究來源為公開的作品評論與設計分析，僅作方向參考，見 [SOURCES](../SOURCES.md) 的既有原則：參考作品只作方向比較。
