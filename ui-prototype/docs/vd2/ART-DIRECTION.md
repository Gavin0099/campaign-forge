## 動畫管線

Idle → Move（有位移才播放）→ Windup → Release → Impact → Recovery → Idle。

`combatPlayback.ts`只管理RAF視覺時鐘；App的確認動作透過Impact callback套用原有固定3效果、位置與一次行動。同步ref擋連點；未命中取消不變更數值，已命中取消不回滾既有效果。畫面切換與hook卸載清除RAF，Reduced Motion保留短暫狀態回饋，抑制姿態切換與VFX。

席恩使用真實PNG影格，不以平移替代走路或揮劍；SVG只作影格定位、腳點錨定及路線平移。原圖有影格跨名義欄界的長劍，因此以30個完整連通輪廓產生metadata，避免裁掉武器；原像素未修改。這不等於逐幀手工修到量產水準，仍需人工檢查體積穩定與腳步。

法術按鈕屬非正式演出展示，不改HP、位置、行動次數、回合或故事；角色缺席時可用現有角色展示VFX，但完整姿態僅席恩具備。展示名稱不是正式技能定案。
