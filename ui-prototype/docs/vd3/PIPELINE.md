# VD3 — 動畫管線決策

本文件在動作程式製作前建立；起迄見 TIME-LEDGER.md，執行基線 main@0300c85。Owner 已判 VD2 美術未通過；工程報告保留為歷史，不代表美術通過。

本輪只交付近戰攻防與 Magic Missile，戰地測繪方向、React / TypeScript、11×9 與現有流程不變。故事 A/B/C、正式職業及完整規則未定案。

## 審查

已檢視 AnimatedActor、combatPlayback、CombatEffects、main 的 showcase、30 格原始 PNG、五人 units 圖集與 VD2 的實機戰場。VD2 以不同生成姿勢替換整個人，臉、短劍比例和外套輪廓隨姿勢變動；敵人只有靜圖。時鐘雖有 Impact，但沒有武器接觸／hitstop／敵人姿態的共同錨點。展示選擇優先席恩，沒有能力身分限制。

| 選項 | 優點 | 成本與風險 | 本輪決定 |
| --- | --- | --- | --- |
| A：逐幀 PNG，人工修幀與節奏 | 自然重繪透視、可以變化輪廓 | 每幀需重畫校準臉、衣服、劍長與腳；目前30幀不具量產一致性。只改播放速度不能消除漂移 | 保留原件與舊版證據，不再生成整批姿態 |
| B：2D cutout，固定圖像部件＋骨架／武器錨點 | 臉和服裝共用原像素、固定劍長；腳點、手與接觸位置可共同計算；雙方可協調 | 關節接縫、紙片感與轉身有限，需實機看關鍵姿態；不是自動取得商業品質 | **採用**，僅兩段演出與必要的受擊目標 |
| 風格化3D（長期比較） | 共用骨架、轉向與碰撞可量產 | 模型／蒙皮／材質／照明／引擎整合成本高，尚無資產、人力與工期實證 | 只列成本，不引入引擎或依賴 |

## 實作契約（製作動作前記錄）

1. 既有席恩與敵人插畫透過 SVG 部件遮罩重用原圖，不修改原始 PNG。固定頭、軀幹、兩節手臂、腿／靴，武器為同一把固定長度的短劍。姿勢由一套連續骨架計算，不能在命中時換成另一張臉。
2. 先接地、再蓄力、短促出手，刀刃終點與敵人胸前共用接觸座標；短暫 hitstop 後胸／肩／頭後仰，最後回復。腳點保持固定，必要移動與原資料位移分開。
3. 增加獨立測試法師原創插畫，與 story party / unitSeeds 隔離；僅測試法師能使用 Magic Missile，席恩只有非魔法近戰展示。準備手勢、三枚凝聚、三條飛行軌跡及共同 Impact 時間。
4. 展示不改遊戲 HP、位置、行動與回合。正式 UI 確認依舊只在 Impact 套用原固定3效果；沒有導入桌上規則、命中骰、法術位或傷害骰。
5. 音效僅使用本地 Web Audio 合成，預設關閉、按鈕明確開啟；取消／卸載停止音源。Reduced Motion 不播放肢體／飛彈／hitstop，但保留文字結果與一次狀態更新。
6. 以實機 GIF、關鍵影格、720p／1080p、連播10次和中止測試驗證。自動測試只能證明工程契約，不能替 Owner 判斷重量感與美術品質。

視覺命題：低飽和手繪人物在墨灰戰場上，以身體和武器動作承載重量；青白三飛彈承載奧術辨識。UI 持續標示展示身份與目標分配，特效不遮住接觸點。

實機迭代：生成法師原件偏寫實長身，與隊伍並列時頭部過小。保留PNG原件，在同一SVG骨架內將身體縮放0.09、頭部在頸點固定放大1.6，使展示約五頭身；所有姿勢使用同一比例。這是動畫部件的執行期比例，不是另生成姿態或改寫原始圖像。施法手部仍對齊同一凝聚點。立繪、量產角色與正式外觀均未定案。
