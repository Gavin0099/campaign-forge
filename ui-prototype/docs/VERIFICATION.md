## 操作重現

1. 開始展示，經營地進渡口，選居民或軍糧。
2. 保留三人，或只留莉妲；確認出發。
3. 點席恩（或莉妲）→第2列第5行→第3列第4行追兵→確認移動與技能。
4. 點確認護送抵達出口→確認完成→返回戰役，檢查同伴與下一次行動。
5. 重新開始，走另一條分支比較。
