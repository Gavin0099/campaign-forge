# 驗收契約：工程、可玩、樂趣與美術分開

目前各列都是未執行的未來門檻，不是本輪測試結果。3–5分鐘完整遭遇戰是實際真人試玩目標；自動點擊所需秒數不能代替它。

## 工程 Gate

| ID | 必須證明 | 最小證據 |
| --- | --- | --- |
| E1 座標／部署 | 99格地景與點擊同源；起點、目標與車隊路線有效；開閘部署不再隔河無解 | 兩分支關鍵路徑／占位檢查；720/1080相同cell的實際點擊與鍵盤紀錄 |
| E2 獨立命令 | 只移動可結束；只攻擊、支援、待命、提早EndTurn皆可；不攻擊也能推進目標 | 正常開局的完整命令 trace，不只測內部函式呼叫 |
| E3 合法性 | 越界／水／斷橋／占位／超步／穿人／倒地／錯方／錯回合／無預算／不可達／過期預覽皆拒絕 | 有效及無效對照；拒絕前後state hash不變、錯誤原因可見 |
| E4 唯一結算 | 雙擊確認、同commandId、舊revision、重複EndTurn／Retry舊callback不重算；outcome只能一次 | 不同command的相同效果可合法存在，不能以內容去重誤殺；before/after HP／預算／回合／進度一致 |
| E5 敵人 | 兩種planner有不同目標邏輯；無路／死目標／占位變動有理由；同state輸入一致 | 固定fixture比對、玩家改站位／HP後意圖改變；一人最多Move＋Attack，EnemyResolve有上限 |
| E6 勝敗 | 兩分支各自**原始完整開局**至少一條成功trace及一條失敗trace；不是注入勝利旗標 | 命令重放可驗證每步合法；記round、alive、boats／convoy；第5輪達標成功、未達標失敗、致命優先、清敵不替代目標 |
| E7 演出／生命週期 | 無動畫、一般速度、Reduced Motion、Esc跳過、背景暫停、卸載再入、重試，都不重扣HP／卡住phase | 相同命令trace最終state hash相同；舊encounter事件無效；演出每段有界且可跳過 |
| E8 回歸／操作 | build＋scope；原兩完整UI路線、缺席角色、結果返回、對白紀錄、Esc、放大文字仍可用；新Demo基本鍵盤可完整完成／Retry | 新版來源綁定的瀏覽器紀錄、720p/1080p實機截圖；不可沿用舊11／23項報告冒充新玩法驗證 |

未來 trace 格式至少含基線／rulesVersion／encounterId／初始配置、每個command與預期revision、接受或拒絕原因、events、每步state hash及終局。fixture可用於測邊界，但**原始開局成功／失敗**必須另跑，防止只測出人工構造的可贏狀態。

初始策略候選（尚未測過，不稱攻略）：開閘優先清絞盤附近騎士、留一人持續守位、其餘攔追擊；封閘優先清車隊路徑、安排護送者跟進，避免自己站在下一格阻擋。對照嘗試只追殺／離開目標／放棄支援。若全部都以相同順序輕鬆贏，或任一分支無合法勝路，記設計FAIL並調部署／HP／期限，不能產假trace。

## 人類試玩與去留

測試順序：代理先自玩查可完成，再至少1名未受操作指導的玩家（Owner或新玩家）實際嘗試；建議之後加第二位。招募／提供遊戲需在可操作成果準備好後進行，不傳送未授權外部訊息。若尚無真人參與，只能標 **ENGINEERING_PASS／HUMAN_PENDING**。

| 記錄欄位 | 判讀方式 |
| --- | --- |
| 測試者／時間／viewport／輸入方式／buildSHA | 匿名化即可；與自動化結果分檔，不能由代理猜填 |
| 開始30秒是否有意識完成一次合法行動；60秒能否說明目標 | 不先教控制；若卡住，記卡點及給過的提示，不能把教完後的成功當無指導成功 |
| 從開始至結果的實際時間 | 目標3–5分鐘；記思考／操作／等待演出時間，過長先減閱讀與演出，過短先查是否不用思考 |
| 一次敵方意圖與回應是否看懂 | 玩家自己描述「它為何追我／堵車隊」；不是問卷裡只按同意 |
| 是否主動重試；第二次改了什麼 | 記實際命令／站位／順序改變與結果，不把代理要求「再玩一次」算自發重玩 |
| 哪個選擇最難、何時覺得無聊／不公平 | 自由回饋原意與代理解讀分開，負評保留 |

預先決定的判準：

- **KEEP（值得繼續投資）**：E1–E8通過；灰盒中至少1位未指導玩家30秒內有意識行動、理解敵方壓力，並主動再試；第二次能指出／執行不同策略。兩分支成功、失敗與不同目標的工程證據齊備。這只是Demo方向keep，不是正式美術或遊戲通過。
- **REFACTOR（有明確可改因素）**：玩家有策略意圖但被單一可定位問題阻擋，如提示不清、追擊過強、護送步數過緊、演出等待過長。一次只改一個變數，留下前後trace與真人觀察；重估時間，不無限延長10h。
- **KILL／縮題**：只靠反覆解說才會操作；忽略目標／只清敵就同樣有效；兩分支只是換文字；沒人想再試且改進必須依靠大量新規則／美術；或到時間盒仍無完整合法循環。保留失敗證據，停止加技能／動畫，縮小問題再提案。

真人缺席是PENDING，不是KILL，也不能自封KEEP。商業美術保持 **OWNER_REVIEW_PENDING／未通過**，B候選沒有因此升格。正式引擎、戰鬥規則、劇情選案仍未決。
