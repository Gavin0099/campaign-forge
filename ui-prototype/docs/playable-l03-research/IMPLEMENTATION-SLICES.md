P1機制PoC的60分鐘包含在3h內，不另加預算。事前選擇load-bearing而非throwaway：現有React架構與99格已存在，這輪要驗證整合循環，因此採獨立 `ui-prototype/src/playable-l03/` 純領域／呈現模組與明確Demo入口，保留既有L03Preview／ArtGate。這是對prototype-fast「編碼前決定是否保留」的具體選擇，不聲稱其建議的每種原型都已執行；也不因工程可延續就預判值得正式製作。

每片證據至少記錄開始／結束時間（含時區）、基線與實作SHA、實際命令、trace或瀏覽器紀錄、PASS/FAIL/PENDING及已知問題。實際投入與等待真人時間分開記錄。不得以「已安排10h」或「程式可build」冒充已玩完。

時間不足依序刪：鏡頭震動／額外粒子→B美術場景套版→非必要快捷鍵／裝飾。保留獨立行動、兩種AI、兩目標、勝敗Retry、狀態不重算、最小鍵盤與真實瀏覽器證據。若核心仍未完成，於10h停止交付未達項與新估算，不用削掉敗北或敵人來湊完整。
