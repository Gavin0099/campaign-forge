# 最小追加授權提案

本輪研究已由使用者明確授權。真正的回合、敵人、治療、勝敗與部署調整超出既有「固定示範UI」；使用者本次又明確要求先提交研究與範圍。因此規格可直接寫，**實作需要下一個明確批准**，不是安裝Skill本身要求確認。

適用界線來自 repo [AGENTS.md](../../../AGENTS.md) 的 L1→L2：

> 正式故事定案、正式戰鬥規則、永久資料、帳號、網路服務、安全設定、費用、公開部署及跨專案寫入，均超出本輪 UI 授權，需回報與取得相應授權。

本提案不要求正式規則授權，而是把新增的**暫定可玩Demo規則**明確限縮，避免以先前UI授權直接擴張。可批准文字如下：

> 授權依本研究的 A 路線，在獨立 codex 分支及 ui-prototype 範圍，進行上限10小時的 Playable L03 Demo。允許保留11×9地形、調整本Demo起始部署與敵數，新增獨立移動／近戰／暫定支援治療／待命／結束回合、兩種敵方策略、兩分支目標、期限、勝敗及重試。數值與配置可為可達性／試玩調整並留版本紀錄，全部是可撤回Demo提案，不改正式故事／G004／G005／S3。可補必要狀態／渲染／瀏覽器驗證及原創簡化物件，保留既有兩流程；不安裝新引擎／runtime依賴、不量產角色或新增關卡。按片驗證可自主接續，正常commit/push；不PR、不合main、不部署／Actions／付費，不碰其他AI worktree。真人試玩與美術審查未取得時如實保留PENDING，不冒稱通過。

這份授權不包括Phaser/Godot PoC、正式規則採用、永久存檔、故事分支合併、S4或24關。角色稱呼和既有代價沿用目前UI候選，不補寫缺來源的故事新稿。不需要提供新登入／憑證。
