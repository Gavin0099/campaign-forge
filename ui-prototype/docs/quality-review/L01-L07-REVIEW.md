# 《碑誓》L01–L07 腳本與逐關戰鬥審查

**狀態　代理審查，不是人類試讀。** 唯讀來源：`story/strengthen-narrative` 分支（`0be4c94`）的 `docs/story/script/ch01.ink`、`ch02.ink`、`globals.ink`，以及 `docs/story/levels/L01.md`–`L07.md`。本文不修改故事、不選案，也不代替 G004。

## 一、前 5 分鐘：玩家知道為何而戰嗎？

**整體來說知道，而且比主流程原型清楚得多。**

做得好的地方：

- 凱倫的動機出現在第二句：他想把見聞帶回騎士團換一次重審，報告第一行卻只寫得出「奉命」。想要什麼、缺陷在哪，一句話就交代了。
- 第一場戰鬥的理由是具體、看得見的：守住瑪歌的旅店和燈芯牆。
- **全稿最好的設計在 L01：** 爬行者繞過活人，直撲燈芯牆（L01.md：「會繞過活人撲向燈芯牆」）。敵人的行為本身就暗示了「裂潮在找魂」，第 4 回合再由托瑪說破。這是機制和故事互相印證的範例，後續關卡應該多用這種手法。

風險：

- **第一場戰鬥前的專有名詞太多。** L01_pre 在開戰前出現約 13 個新名詞：燈芯屋、騎士團、鄧肯、灰燈學院、韋恩教授、名鑰、界碑、黎明誓院、北岸、收容禮、議庭、裂潮、守碑騎士。其中「北岸四百人的收容禮」與「議庭」要到 L03 才有作用。
- **建議：** 把收容禮與議庭的說明移到 L01_post 或 L02_pre，L01_pre 只留下玩家打第一仗需要的東西：旅店、瑪歌、燈芯牆、那三口箱子。這只是建議，修改故事正文需要另外授權。

## 三、K1 的戰鬥面不對稱：開閘可能變成「標準答案」

試讀問卷已經在問「K1 哪個選項像標準答案」。從戰鬥面看，答案很可能是開閘：

| | 開閘 | 封閘 |
| --- | --- | --- |
| L04–L07 可用的戰鬥單位 | 多一名遊俠歐朵（L05 起） | 沒有 |
| L05 提示 | 歐朵直接說出「站在燈柱的影子裡」 | 凱倫自己注意到（同樣的資訊，只是較晚） |
| L06–L07 戰鬥收益 | 無 | 無。筆記只影響對白，和 L07 之後的劇情 |
| 第一章戰鬥節奏 | 守、護送、守、護送，交替出現 | 守、護送、護送、護送，連續三場護送 |

封閘的好處（名鑰、伊瑟拉的好感）都在劇情層，而且要到 L07 之後才兌現。重視戰鬥的玩家會覺得開閘「多一個人、打起來也比較有變化」。這會讓 K1 原本想問的價值選擇（眼前的孩子，還是看不見的四百人），在戰鬥面被「要不要多一個隊友」覆蓋掉。

**建議（不修改故事，只是提案）：** 在 L05–L06 給封閘路線一個戰鬥面的對應收益。例如：魏德的筆記記載書架的符文順序，L06 的光環時限 +2 回合；或者筆記指出石像的弱點。這樣兩邊在戰鬥上各有所得，K1 才會回到價值選擇。

收留薩溫也有類似的問題：收留就多一名單位，加上 L06 頭目弱點的提示和 L07 的第三個選項；拒絕只換來蕾絲 +1 信任。程度比 K1 輕，列為 P2。

## 四、L07 的目標 ② 是假目標

L07 的戰鬥目標寫著：「② 保護小昆、星盤與（若在隊）薩溫」。但在腳本裡：

- 戰鬥結束後，`L07_choice` 一定會讓玩家三選一，另外兩個一定會失去。
- 戰鬥寫入的唯一結果是 `l07_saved`（撤出的倖存者人數）。

所以玩家在戰鬥中保護得再好，目標 ② 的結果都由戰後選項決定，戰鬥表現不會產生任何影響。玩家會在這裡第一次發現「戰鬥目標可以是假的」，傷害之後所有關卡的可信度。

**建議（擇一）：**

- 讓目標 ② 決定戰後選項的範圍。例如第 7 回合時，只有我方單位身旁 2 格內的對象可以被選；守得好的玩家能在兩個之間選，守不好的只剩一個。
- 或者把目標 ② 從戰鬥目標中拿掉，改在戰前明說「莫瑞安會帶走一樣東西，你只能護住一樣」。誠實的必輸比假裝能贏好。

## 五、NPC 敗北條件的密度

L01（瑪歌）、L04（瑪歌）、L06（小昆）三關都有「某個 NPC 倒下就輸」。這些 NPC 都是心之錨，用他們當敗北條件是對的，玩家會在乎。但七關中有三關都是這樣，NPC 的行為必須完全可以預測，例如固定路線、不亂跑、在地圖上標出下一步。否則玩家會把失敗歸咎於 AI，而不是自己的判斷。
