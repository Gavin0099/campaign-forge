## 技術可行性與限制

兩案均已進實際 React 畫面：角色、HUD 和可操作檢視為獨立圖層，非生成一張帶假按鈕的截圖。沒有加入新引擎或套件；但這是**可執行的靜態品質樣板**，不是新美術已接回移動、技能與勝敗的戰鬥頁。

A 適合定鏡 2D 管線，後續需拆出橋欄、岸邊、船、NPC 前後景，制定地面投影／可走區並重繪校準，沿用角色 billboard。B 本輪是 **2.5D 外觀的預繪樣板，沒有 3D mesh／rig／高度場**；定鏡落地方式與 A 相同。若要旋轉鏡頭、連續高度與動態光照，須另外製作或建模，不能從這張圖推論已具備該能力。

五個獨立人物圖層足以驗證選取與前後遮擋樣式；Teo／Maggie、群眾、船與車隊目前烘在底圖，**不能直接做獨立動作或移位**。下一階段優先為選定方向分層、精確地形契約與人物視角校準，再考慮動畫；不是直接量產角色。

新增四張 PNG 約 9.49 MB（兩底圖各 1672×941；B 三人圖集 2172×724、敵方 1774×887，後兩者含實際 alpha）。兩案同時開發保留原圖；正式交付仍需壓縮／分包與載入量測。本輪沒有 CWV、低階 GPU 或商用效能通過宣稱。

底圖在 1920×1080 顯示時約放大 15%，不是原生 1080p 繪製；角色 PNG 外緣與 B 圖集頭頂留白也仍需美術清理。沒有用圖片處理腳本補畫或覆寫生成原件。
