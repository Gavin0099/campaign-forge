# Campaign Forge UI 展示原型

此目錄只驗證 Steam／PC 戰棋 RPG 的介面流程。展示採候選 A《界碑之外》的渡口情境；A、B、C 仍是獨立提案，沒有選案，也沒有正式 24 關劇本。人物、對白、分支文字、章名與示意地圖集中於 [`src/data.ts`](src/data.ts)，可替換。

## 啟動

需要 Node.js 16 以上。依賴固定在 `package-lock.json`。

```bash
cd ui-prototype
npm ci --ignore-scripts
npm run dev
```

打開 Vite 顯示的本機網址。`npm run build` 執行 TypeScript 檢查並產生靜態展示檔。此專案只用於桌面瀏覽器展示，未決定正式遊戲引擎。

## 一關流程

主選單 → 戰役旅程 → 營地／同伴 → 渡口對話與命令 → 戰前部署 → 戰場操作 → 戰後結果 → 戰役旅程。主選單的「開始展示／重設」會清除這次展示的選擇與戰鬥進度；一般返回保留已選的命令及出戰名單。

戰場依序點選我方角色、斜紋移動格、圈線技能範圍內的敵人，再確認行動。至少確認一次行動後，「確認護送抵達出口」會顯示二次確認並進入戰後結果。這是固定資料的操作演示；河道禁行、三格移動、兩格技能與固定效果 3 皆不是正式規則。場上敵人不進行完整回合，失敗條件也未模擬。

## 設計與資訊層級

以戰役緣由和人物後果帶玩家進入戰鬥。旅程先顯示當前節點，後續章節只有未揭露占位；營地先說明人物為何同行、擔心什麼與拒絕條件；抉擇先列可知利益、代價與不確定性。戰場以格線為視覺中心，右側只放操作、預覽及目標。結果先交代人與資源的變化，經驗與物資放在其後。

視覺已接入 built-in image_gen 生成的四位人物、五種戰場小人、渡口地景與戰役地圖；均為原創展示提案，不含商業遊戲素材。對白可展開紀錄，設定可放大文字。Tab、Enter／空白鍵與 Esc 有明確操作；手把只記錄預計映射，沒有實作或測試。格線中的敵我以 ◆／▲、姓名與不同底色區分，範圍另有斜紋及邊線。

## 仍需驗證的設計

故事選案會改變人物、章節與戰役節奏。正式戰鬥規則會改變部署、可達範圍、回合資訊和行動預覽。玩家測試須確認抉擇資訊是否足以理解風險、戰場目標是否清楚，以及 1280×720 的閱讀負擔。原型中的任何假設都不代表已確認設定。
