# Campaign Forge

為 Steam／PC 原創奇幻戰棋 RPG 先建立主角與故事戰役，再決定製作方法。

本批完成三個故事提案與比較，所有候選設定均待 Gavin 選擇。下一步停在 [故事選擇關卡](docs/review/STORY-GATE.md)。

## 保存狀態

2026-10-20，企劃的公開保存位置為 [Gavin0099/campaign-forge](https://github.com/Gavin0099/campaign-forge)，GitHub API 已確認可見性為 Public。此版本包含三個獨立故事候選、比較審查與 S0 至 S10 的切片計畫；內容工作完成至 S3。交付方式與驗證標準見 [執行紀錄](docs/EXECUTION.md)。

## 閱讀順序

1. [三案比較與推薦](docs/review/COMPARISON.md)
2. [A《界碑之外》](docs/candidates/A-beyond-the-boundary.md)，測繪副官帶領邊區撤離，在父親的責任與自己的命令之間作選擇。
3. [B《欠命人的遠行》](docs/candidates/B-the-debtbound-road.md)，前契約騙徒集結受害者，策劃一場必須處理自己罪責的奪契行動。
4. [C《最後一頭守路獸》](docs/candidates/C-the-last-waybeast.md)，被當成財產的石皮引路者，護送最後一頭成年巨獸，爭取決定道路去向的資格。
5. [故事選擇關卡](docs/review/STORY-GATE.md)，只需先選 A、B 或 C，或點出希望修改的核心。
